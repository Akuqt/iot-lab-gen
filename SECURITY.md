# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it to us. We take all security concerns seriously and will address them promptly.

### How to Report

1. Email us at [me@ialfaro.com](mailto:me@ialfaro.com).
2. Include a detailed description of the vulnerability.
3. Provide steps to reproduce the issue, if possible.

We will acknowledge your report within 48 hours and provide updates as we investigate and resolve the issue.

Thank you for helping us keep our project secure!
