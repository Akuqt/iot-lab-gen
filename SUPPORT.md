# Support

Thank you for contributing to this project! If you need assistance, please refer to the following options:

## Getting Help

1. **Documentation**  
   Check the project's documentation for detailed guides and FAQs.

2. **Issue Tracker**  
   Report bugs or request features via the [issue tracker](https://github.com/Akuqt/iot-lab-gen/issues/new/choose).

3. **Community Support**  
   Join the discussion in our community forums or chat channels.

4. **Contact Maintainers**  
   For urgent matters, contact the maintainers directly at [me@ialfaro.com](mailto:me@ialfaro.com).

We appreciate your feedback and contributions!
